# LA CAGE — APK Android

Jeu de streetball « La Cage de Bécon » (Courbevoie). Ce dépôt sert uniquement à distribuer l'application Android.

## Installer

1. Télécharger **LaCage.apk** : https://github.com/LiftStudio/la-cage-apk/releases/download/apk-latest/LaCage.apk
2. Sur le téléphone, ouvrir le fichier téléchargé ; autoriser l'installation d'applications inconnues si Android le demande.
3. Lancer **LA CAGE** (le jeu est en paysage).

La dernière version est toujours dans la release **apk-latest** : https://github.com/LiftStudio/la-cage-apk/releases/tag/apk-latest
